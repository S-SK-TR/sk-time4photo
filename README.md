# SK-Time4Photo

Fotoğraf zaman çizelgesi uygulaması

## 🚀 Özellikler

- 📸 Fotoğraf yükleme ve yönetme
- 🕰️ Tarihe göre otomatik gruplama
- 📅 Yıllara/aylara göre zaman çizgisi
- 📱 Mobil uyumlu responsive tasarım
- 🌐 Offline kullanım desteği
- 🎨 Animasyonlu UI
- 🔄 Persist edilen kullanıcı seçimi
- 📝 Timeline isimlendirme

## 🛠️ Kurulum

1. Bu repo'yu klonlayın:
```bash
git clone https://github.com/[kullanici-adi]/sk-time4photo.git
```

2. Gerekli bağımlılıkları yükleyin:
```bash
npm install
```

3. Uygulamayı başlatın:
```bash
npm run dev
```

## 📦 Vercel Deploy

Uygulama otomatik olarak Vercel'e deploy edilecektir. Deploy tamamlandığında link paylaşılacaktır.
